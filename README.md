# Crescent Mail React app

This is the new React mailbox app, separate from the existing developer sending console in `../mailer/frontend`.

Run it with:

```bash
npm install
npm run dev
```

The first vertical slice includes the responsive Harbor Mail shell, mailbox navigation, search, category tabs, typed mail fixtures, selectable message rows, reader pane, and docked composer. The migration plan is documented in `../mailer/frontend/REACT-MAIL-MIGRATION-MAP.md`.
